# Origin

This app started from the official Even Realities template
https://github.com/even-realities/evenhub-templates/tree/main/asr
on 2026-11-23. Kept from the template: Vite/TS setup, tsconfig, index.html shell,
the createStartUpPageContainer / textContainerUpgrade / onEvenHubEvent pattern
and the click-is-eventType-0 handling. Everything else (state machine, screens,
API client, WAV encoder, mock) was written for ShopTill.
